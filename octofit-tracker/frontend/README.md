# Octofit Tracker — Frontend (starter)

This folder contains a minimal React starter app for the Octofit Tracker frontend.

Quick start

1. Install dependencies:

```bash
cd octofit-tracker/frontend
npm install
```

2. Start development server:

```bash
npm start
```

Notes

- This is a small scaffold to be replaced with a full create-react-app or Vite project.
