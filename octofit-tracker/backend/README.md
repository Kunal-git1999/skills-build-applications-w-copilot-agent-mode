# Octofit Tracker — Backend (starter)

This folder contains a starter layout for the Octofit Tracker backend (Django).

Quick start

1. Create a Python virtual environment and activate it:

```bash
python3 -m venv venv
source venv/bin/activate
```

2. Install requirements:

```bash
pip install -r requirements.txt
```

3. Use Django's management commands to start a real project or continue building from here.

Notes

- This is a lightweight starter layout meant to be extended; the real Django project should be initialized with `django-admin startproject` and proper configuration.
- See the top-level `.github/instructions/octofit_tracker_setup_project.instructions.md` for the project's required dependencies and dev guidance.
